## 验收标准（承接修订后 issue）

1. 经管理 REST API 新建、查看、编辑、删除活动；稳定 ID；取消不写；删后列表/详情/刷新一致；同进程删空后前端不得用种子重生已删活动；未知详情 ID 明确未找到（新版 `campaign-http-check.mjs` 的 `unknown_campaign` 步骤待执行器回填结果）。

3. 普通组按 groupId、包臂按 bundleId+groupId；目录缺失/不可用时保留原 ID/名称并标不可用，不得静默改绑；不可用引用不能作为有效新保存。
4. 展示类动作须有展示位；推送不得带展示位；前端可补/对齐 `show-image`/`action-show-image` 正反例。
5. 同活动同展示位：无法证明互斥且无决策表则拦截；同包不同臂可证互斥则允许；推送不参与。服务端写入校验为准，前端提示一致。

   受众删除目前由浏览器读取服务端占用后拦截；服务端写入边界的最终校验经用户决定已拆到后续 issue（编号待产品经理给出），本 PR 不扩 scope、不声明已满足该部分。
