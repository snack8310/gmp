# 运营流程立体展示 Demo

## 任务分类与问题本质

- 类型：新需求开发。等级：小任务。
- 背景：用户需要在现有项目里直观看到人群进入、策略分流、触达与结果，而非阅读 CLI 输出。
- 目标：提供可交互的空间运营沙盘，帮助讲解流程；不是生产编排器，也不是领域模型运算结果的可视化。
- 硬约束：隔离展示入口，全部构造数据，不改现有核心语义、接口、CLI、持久化或工作流权限；不自动合并或部署生产。用户另行请求可在线查看的私有预览，不改变生产部署边界。
- 候选取舍：普通流程图不满足空间感；WebGL 在验证环境不可用。采用 SVG 渲染自行构造的三维坐标、实体面和投影，配合人群动效，不引入渲染依赖或第三方源码。
- 参考仅为公开页面的空间化表现方法，无第三方代码或素材进入仓库。

## 范围与验收标准

- 新增 `gmp-core/cmd/gmp-flow-demo/`，以 Go 标准库嵌入静态前端；现有 `gmp-demo` 不变。
- 人群池 → 策略 → A/B 分流 → 短信 / Push / WhatsApp / IVR → 成功 / 失败，实体有体积、空间位置与流动对象。
- 播放、暂停、重置、倍速、示例场景切换、时间定位、节点详情及视角控制可用。
- 同一场景与时间得到同一结果；未进入 + 处理中 + 成功 + 失败 = 总人群。节点累计到达不作为互斥分母。
- 成功仅指模拟触达回执成功，不代表业务转化。失败为终态；处理中包含路上与等待回执，不当成失败。
- 暂停不推进模拟时间，重置归零并暂停；切场景重置；重复操作不积累动画循环。
- 不依赖 WebGL；小屏布局可用，键盘能操作节点与控件；减少动态效果偏好下默认暂停且不播放粒子移动。
- 界面、文档使用中文；代码注释和提交信息使用英文。遵循既有暖白 / 深蓝色彩与语义色边界。
- Go 构建、静态检查、回归及新增 HTTP 验证、JavaScript 模型测试和文档检查通过，并提供浏览器交互与截图证据。

## 非目标与影响面

- 不实现生产分桶、渠道发送、真实回流、重试、对照组、实验指标或持久化；演示分组只是固定脚本。
- 不接 API、数据库或任何外部服务。服务仅提供随二进制打包的静态资源；默认回环地址。
- 不改变 `docs/domain/`、既有分层或 CI 权限。前端不读取用户输入名单。
- 不声称物理仿真、WebGL 或生产性能已验证。

## 高风险与人工确认

- 通用高风险判定（核心语义、接口契约、执行与重试、持久化、安全边界、实现一致性、跨模块影响）：均否。仅新增隔离展示命令与模拟脚本，无真实领域或外部服务依赖。
- 项目高风险清单（事件、组件、执行、受众、分桶、统一契约、权益、资格、渠道、存储、幂等、迁移、授权、决策、优先级、依赖分层、时间注入）：均不改变。展示时钟不替代领域时间来源。
- 对外破坏性变更：否。实施前额外人工确认：不需要。用户已明确请求展示 demo。
- GitHub Issue / 分支 / Draft PR 的外部写入授权：已确认。用户明确同意创建 Issue、推送独立分支并开 Draft PR；不合并、不部署生产。关联 issue #48。用户另行要求无需下载的页面，私有预览独立交付。
- 最终人工确认：待确认。

## 风险三档

- 真风险（阻断）：当动画和统计来自不同状态时会出现人数不守恒。模型统一派生位置和统计，边界时间以测试验证。
- 真风险（阻断）：当反复播放或切换场景时会累积动画循环。单时钟控制器、可注入调度器并测试。
- 真风险（仅观察）：SVG 投影不提供真实光照/材质/碰撞，极端视角可能遮挡对象；限制视角范围并保留节点列表。
- 伪风险：真实发送风险不成立，本入口没有网络请求、渠道配置、名单输入或生产模型调用。
- 未讨论项：空间可读性、移动端点选和减少动态效果是否可用，交独立评估器核对截图、控制器测试和浏览器操作证据。

## 最小验证与评估重点

- `go build ./...`、`go vet ./...`、`go test ./...`、`gofmt -l`、现有 CLI 冒烟。
- 新增模拟模型与时钟测试：全程计数守恒、确定性、失败/延迟差异、暂停/恢复/重置/重复启动、结束后停止。
- 新增静态 HTTP 测试：页面与资源可读、未知路径与写方法拒绝、无外部调用约束。
- JavaScript 语法检查、文档一致性检查、浏览器控件及窄屏/键盘/截图核对。
- 新增约束由测试而非新协作规则承接；JavaScript 用例本地执行，现有 CI 未配置 Node，不声称已纳入 CI。
- 不覆盖真实渠道、真实转化率、跨浏览器全矩阵、GPU 光照、端到端生产链路。
- 评估器重点攻击：终态边界、统计重复累加、timer 泄漏、视角切换影响数据、低动态偏好、暖白场景的可读性；判断是否有值得沉淀的长期规则。
