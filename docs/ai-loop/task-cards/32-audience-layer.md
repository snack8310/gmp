## 任务分类

- 类型：新需求开发
- 等级：**大任务**

## 问题本质

- **用户表面请求**：写 `audience` 层。
- **要解决的真实问题**：把受众服务最硬的那条约束从文档里的一句话变成会失败的测试——**一份人群定义必须同时够枚举与判定，且两者结果一致**。`audience-user-stories.md` 明写，被删掉的那版设计只做了枚举，所以答不了资源位。两个方向不一致**不会报错**：资源位那条线只问单个 uid，没有任何东西会去跟枚举结果对账。
- **硬约束**：H1–H10，逐条见 issue #32。本卡不复述，避免与来源分叉。
- **已考虑并否决的更本质解法**：见 issue #32「A 是不是唯一方式」表（只做枚举 / 判定用枚举实现 / 先做通用条件语言 / 直接接真实数据源）。
- **成功标准**：issue #32「验收标准」每条都能被一个命令或一个测试判定，且在 CI 上真跑。

## 范围

- **范围内 / 非目标**：见 issue #32。**特别地：不修改 `docs/domain/` 的任何语义**，发现规格有洞走澄清。
- **影响面**：新增 `gmp-core/audience/`；修改 `gmp-core/internal/arch/` 的检查与用例。`experimentation` 包不改动。
- **外部系统读写影响**：无。不接数据库、不接网络。

## 人工确认

- **是否需要实施前人工确认**：**是**（`risk/high`）。
- **需要确认的问题**：以下四项本轮**按既定先例自行裁定并如实标注**，不阻塞实施；若人工不同意，回退成本限于本轮产物。
  1. **人群定义不可变**（U2）——与 `experimentation` 的定义一致。类比是否成立交评估器攻击。
  2. **模式（真实 / 演练）不设零值**——领域文档记了「调用方必须传对，传错就静默染色」这一代价。按「约束落地优先级」第 1 层，把它从「传错」变成「不传即失败」。
  3. **回流粒度是来源的必填属性，不设全局常量**——事实 19 只说「小时级够用」，把它写成代码里的 `1 * time.Hour` 等于臆造一个仓库证明不了的默认值。
  4. **只做三类具体条件，不做通用条件语言**——PR #14 因范围过大整份作废。
- **已确认事项与来源**：技术栈 Go（issue #23 的 H1，人工裁定，诚实性边界同前）；`gmp-core` 为本仓库内子项目（#21）；份号从 1 起（issue #23 的 Q4，人工裁定）。

## 最小验证集

- **必跑命令**：`go build ./...`、`go vet ./...`、`go test ./...`、`gofmt -l .`、依赖方向检查及其变异、`python3 test/docs/consistency_check.py`。
- **必补测试**：issue #32「验收标准」逐条——枚举与判定等价、判定不经由枚举、份号条件走实验服务、演练不染色、模式必填、回流时间窗守卫、回流粒度必填、依赖方向及其变异。
- **必查边界**：空定义（无条件）、条件全不命中、来源为空、同一定义重复求值、份号条件引用不存在的分流。
- **可接受的替代证据**：枚举与判定「同一时刻观察到同一份数据」在内存实现下天然成立，**不构成对真实实现的证明**，如实记为内存实现测不出的一类（U3）。
- **本次不覆盖项**：`campaign` / `scenarios` 两层；场景 ①③④⑤；真实数据源与存储；预估规模、解释在/不在、未解析条目统计；人群定义的生命周期；跨来源的定义。

## 评估器重点

- **需要重点攻击的反例**：
  1. **判定悄悄走了枚举**——两者「一致」是因为它们其实是同一条路径，等价断言因此空转。
  2. **模式在求值链上有断点**（U5）：定义同时含份号条件与其他条件时，演练模式是否贯穿到每一次对 `experimentation` 的调用。
  3. 等价断言的样本是否足以证伪——条件全命中或全不命中时，两个方向都返回相同结果，断言不产生区分力。
  4. H5 是否被绕开：`audience` 是否只通过 `(键, 定义) → 份号` 触达实验服务。
  5. 「人群定义不可变」这个类比（U2）是否真的成立，还是照搬上一层。
  6. 依赖方向检查扩到 `audience` 后，变异用例是否同步扩了——只扩检查不扩变异等于没扩。
- **需要检查的历史规则**：上方规则级命中清单逐条，含判定不适用的两条。
- **需要核对的验证证据**：必跑命令的真实退出码；依赖方向变异实证；CI 的 `headSha` 等于送审 SHA。
- **需要判断是否新增抽象记忆**：候选——「同一份定义的两个方向必须用性质测试锁死，不能靠两边各自的用例」。由评估器裁定，主 Agent 不预判。
