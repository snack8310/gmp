# #66 前端：实验人群包发布与统一引用目录任务卡

## 任务分类与本质

- 类型：新需求开发；等级：大任务。跨受众页、实验页、活动只读详情与浏览器本地持久化；命中 `risk/high`（本地缓存兼容、跨页引用失效）。
- 表面请求：前端 demo 发布实验人群包 + 统一引用目录。真实问题：活动详情仍以静态 `REFERENCE_CATALOG` 的普通组/包臂为可用性真源，与受众/实验页编辑数据断开，无法证明发布身份、跨活动复用与失效传播。
- 硬约束：承接 #64/#65 与 AQ1–AQ3；包归受众侧，分流本体归实验侧，活动挂人群组；默认不改 `gmp-core`；仅内存/浏览器本地；中文主名「人群组」「实验人群包」；合入前产品再问用户放行。
- 已否决：继续扩充静态假目录——只能增加展示样例，不能证明发布身份与失效传播。
- 成功标准：issue #66 验收标准 1–8 由自动化与真实浏览器主路径证明；本机命令与未覆盖项写入变更证据。

## 验收标准（承接 issue）

1. 受众侧可明确发布包：绑定已保存演示分流及同一来源完整 A/B/对照臂；包与各臂有稳定唯一 ID；缺臂/重复份号或 ID/异源或无效分流不可发布；对照臂可不挂投放项仍可见。
2. 「已发布」与「可被活动有效引用」分开；实验侧提供最小显式运行/停用状态；非运行中不得产生有效新引用；停用后旧包/旧臂失效，再运行不自动复活。
3. 同一引用目录列普通组与已发布包内臂（身份、名称、类型、可用性）；仅保存 `experimentId` 的旧配置不得误认为已发布包臂；新增/发布/改名/停用后受众页与活动详情读同一目录，刷新一致。
4. 活动普通组引用按目录组 ID 解析；改显示名不改身份；目录缺失/不可用时不以同名静态种子冒充有效。
5. 包臂引用按包 ID + 组 ID 解析；至少一构造活动证明同一已发布臂可被多活动复用；对照臂无需强制投放项。
6. 被引用包/臂禁止静默消失：破坏性删除须阻止；停用/缺失等失效在原引用处保留原 ID、名称并标不可用。
7. `gmp-audience-demo-v1` 历史缓存可兼容读取；新字段不得静默清空旧数据，不得把缺状态旧实验臆断为运行中；存储不可用/损坏沿用提示与会话降级；离线单文件导出仍能运行。
8. 更新 README、相关测试与 `docs/history/changes/`；覆盖发布、目录、活动引用、失效/保护主路径并回归深链与离线导出；记录命令结果与未覆盖项。

## 范围、影响与非目标

- 范围内：`frontend/demos/operations-flow/` 受众/实验/活动只读消费面、统一目录派生、本地存储扩展、测试、README、任务卡与变更证据。
- 非目标：正式指标/显著性/AQ3 双视图 UI；生产存储与多用户同步；Flow 编辑；活动完整 CRUD / 投放装配编辑器 / 流程边编辑；默认不改 `gmp-core`。
- 外部读写：仅浏览器 `localStorage`（及现有会话降级）；无生产服务。动作构造目录可保留静态；静态普通组/包臂不再充当引用真源。

## 已确认实施方案

### A. 本地缓存兼容

- 继续使用键 `gmp-audience-demo-v1`；持久化版本升到 **4**。
- v4 载荷在现有 `audiences` / `experiments` 上新增：
  - `bundles`：已发布实验人群包（稳定 `bundleId`、名称、绑定分流 ID、各臂 `groupId`/份号/臂名、发布时分流修订快照等最小字段）。
  - 实验运行态：在 `experiments` 项上增加显式 `runtimeStatus`（建议枚举：`running` | `stopped`）；**缺字段一律视为 `stopped`**，不得默认 `running`。
- 读取：继续接受 version `1|2|3|4`。v1–v3 缺 `bundles` → 空数组；缺运行态 → `stopped`；沿用现有 v1/v2→v3 入口兼容与「下次保存才改写」策略。未知版本或损坏 → 现有会话降级提示，不静默清空键。
- 写入：仅在成功校验后写 `version: 4`；存储不可用时会话内可改、刷新丢失（现有行为）。
- 兼容边界写进 README 与变更证据：浏览器本地演示，不声称生产就绪/跨设备同步。

### B. 统一引用目录与失效

- 派生函数（建议名仅实现用）从「已保存普通人群定义 → 普通组」+「已发布包内臂」生成同一目录；每项含稳定 ID、显示名、类型（普通组 / 包臂）、可用性、包名/臂名（若适用）。
- 活动详情只读解析：普通组按 `groupId`；包臂按 `bundleId` + `groupId`。展示优先用目录当前名；可用性仅由统一目录判定。
- `campaign-activities.mjs` 内静态 `REFERENCE_CATALOG.groups` / `.bundles` **退出可用性真源**；样例活动的引用 ID 改为对接 demo 默认种子目录（或启动时写入默认可发布种子），动作目录可仍静态。
- 失效：分流停用 → 该分流下已发布包/臂标不可用；再次运行不复活旧包。目录缺失同失效。活动引用处保留快照 ID/名称并明确「不可用」。
- 保护：若包或臂仍被任一浏览样例活动引用，禁止破坏性删除（抛错/拦截）；未引用允许删除。
- 「已发布」≠「可有效引用」：包可存在于目录但 `available=false`（例如分流已停用）。仅保存了 `experimentId` 的受众配置不进入包臂目录项。

### C. 发布入口

- 受众侧提供明确「发布实验人群包」动作（非「保存人群配置」）。校验：分流已保存、同源完整 A/B/对照、份号与 ID 唯一、分流当前可产生有效新引用（运行中）。发布分配稳定 `bundleId` 与各臂 `groupId`。
- 实验侧最小运行/停用控件；固定演示比例保留，不做比例/白名单/加载逻辑编辑器。
