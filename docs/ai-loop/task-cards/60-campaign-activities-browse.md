# 任务卡：运营域活动浏览 Demo（只读）

- 关联：issue #60；规格 issue #59；里程碑「运营活动浏览 Demo（只读）」；基线 `7ad2027`。
- 类型：新需求开发；等级：小任务。仅扩展独立前端 Demo，不改变核心领域语义、外部契约或存储格式。

## 背景、目标与范围

现有运营页只有概念卡，无法从活动进入投放项和活动流程的可读实例。目标是在运营域用虚构本地数据展示活动列表、详情、投放项和回执边，保留组合页的装配与播放。

- 范围内：`frontend/demos/operations-flow/` 的种子与引用目录、校验、列表和详情、哈希子路由、样式、离线导出、测试与 README；本任务卡和变更证据。
- 非目标：CRUD、发布、执行、流程图编辑、真实数据与服务、跨页同步、活动状态机、排期等待配置；不改 `gmp-core/`、`docs/domain/` 或 #57/#58 验收语义。
- 已否决的替代方案：继续只展示概念卡无法让读者辨认活动与投放项、活动流程的关系；在组合沙盘增加活动入口会混淆运营浏览与组合播放职责。
- 影响面：`app.mjs` 的路由调用点、`index.html` 运营段、`style.css`、`export.mjs`、对应测试与 README。现有受众/实验编辑、组合播放及 localStorage 数据格式须保持兼容。
- 外部系统读写影响：运行时仅读取本地静态种子；无新增 API、数据库、缓存服务、消息队列或渠道读写。原受众/实验缓存行为不变。

## 验收标准

1. 保持受众、实验、运营、组合导航顺序；`#campaign` 概念卡进入列表，列表按稳定 ID 进入详情；运营子路由高亮运营并支持刷新、前进、后退。
2. 未知活动 ID 显示未找到及返回链接，不选择其他活动；离开组合进入运营子路由暂停播放。
3. 每个投放项展示单一动作与单一人群引用；普通组与实验人群包臂区分；不可用引用保留原值并标记。
4. 详情的活动流程使用只读关系表，端点含 ID，显示成功/失败回执；无投放项、无流程对象、无边及空列表分别显示指定空态。
5. 运营无编辑、拖拽、连线或播放；组合功能和原缓存兼容；HTTP 模块版与离线导出版均能访问列表/详情。
6. 前端测试、改动 JS 的 `node --check`、文档一致性检查及 `git diff --check` 通过；浏览器桌面、390px、键盘如未验证须登记。

## 入口检查

### 问题本质与硬约束

真实问题是现有概念页缺少可追踪的活动实例，读者无法验证一活动多投放项及活动流程边的归属。采用只读本地展示，稳定 ID、互斥人群引用和正常种子校验；异常引用独立构造、不补默认值。活动流程仅展示动作回执条件，不求值、不执行。维持「模拟数据 · 不会真实触达」。

### 高风险项与人工确认

| 判定范围 | 是否命中 | 依据 |
|---|---|---|
| 通用判定标准 1–7 | 否 | 本次只增加本地展示，不改变核心模型、被调用接口、执行顺序、持久化结构、权限或多实现一致性。 |

### 风险三档

- 真风险（阻断）：当正常种子的 ID 或引用不一致时，列表、详情与边会指向错误对象；加载时校验唯一性、引用及同活动端点，测试验证拒绝异常。
- 真风险（阻断）：当失效构造引用被替换成目录中的其他对象时，会掩盖错误；异常样例独立保留原引用并显示「引用不可用」。
- 真风险（阻断）：当运营子路由绕开原导航时，组合播放可能在隐藏页继续；路由回归验证暂停与 `aria-current`。
- 真风险（仅观察）：处理器测试无法证明实际浏览器在 390px 的表格可读性与键盘焦点；可用浏览器走查，缺失时如实记录。
- 伪风险：只读关系表没有执行入口，不会产生真实触达或修改核心；不为此建设执行引擎或图编辑设施。
- 未讨论项：同名投放项或异常引用在窄屏下是否仍可辨？交评估器重点检查渲染与可读性。未知运营子路径如何降级？采用回到运营概念页，但保持运营高亮。
