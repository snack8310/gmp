# gmp-core 第二轮：audience 层，枚举与判定的等价

关联：issue #32

## 背景

`experimentation` 层已落地（#23、PR #27）。依赖分层的下一层是 `audience`，它只允许依赖 `experimentation`。

本轮真正要解决的不是「写一层代码」，而是受众服务最硬的那条约束——它此前只是文档里的一句话：

> **枚举和判定是同一份人群定义的两种用法，但性质相反。一份定义要同时满足这两种。**

`audience-user-stories.md` 明写，被删掉的那版设计只做了枚举，所以答不了资源位。两个方向不一致**不会报错**：资源位那条线只问单个 uid，没有任何东西会去跟枚举结果对账。

## 关键实现

**领域模型（`gmp-core/audience/`）**

- **只提供人群定义一样东西**，用法只有枚举与判定两种。两者是**各自独立的入口**：枚举走来源的全量遍历，判定走单点查找。
- **份号是一个普通条件**。引用「在分流 E 里落第 N 份」与「消费满 100」同类，本层**不自己分桶**——只通过实验服务唯一的入口 `(分流键, 定义) → 份号` 去问，把答案当成关于这个人的一个事实。
- **uid 到分流键的转换只发生在一处**，并在注释中写明了理由：实验服务不知道键代表什么，所以「对齐的两次传的是同一类东西」这个责任归本层，因为本层是知道自己传的是 uid 的那一方。
- **模式（真实 / 演练）没有可用的零值**。领域文档记了这条能力的代价——「调用方必须传对，传错就静默染色」。用布尔值会让错误的那个成为零值，忘记传就等于真实运行。本轮把它变成**不传即失败**。
- **模式贯穿整条求值链**：份号条件在演练模式下走「只读问一下」，否则演练会通过这个条件把人染上，而在别处看起来一切正常。
- **时间以数据形式进来，本层不读时钟**。领域文档把「4 小时未读」这样的时间窗放在人群定义里，而 #23 已裁定核心模型无时间概念。解法是：来源（在核心之外，它有时钟）报出「这个事件发生在多久以前」，本层只拿它跟配置的窗口比大小。**本层从不问「现在几点」。**
- **回流粒度是来源的必填属性，不设全局常量**。事实 19 说的是「本平台自己的回流小时级够用」，把它写成代码里的一个常量等于为任意来源臆造一个仓库证明不了的默认值。**未声明粒度的来源无法承载时间窗条件**。
- **人群定义不可变**。一份定义可能被多个投放项同时引用，就地改会在别人不知情的情况下改变他们要的东西。

**依赖方向门禁（`gmp-core/internal/arch/`）**

分层表改为数据驱动，`experimentation` 与 `audience` 并列其中。**变异用例同步扩到每一层**——只扩检查不扩变异等于没扩。新增一条反向用例：`audience` 依赖 `experimentation` 是允许的，必须不被误判为违规。

## 风险与未覆盖项

**真风险（仅观察，如实说明）**：

**等价断言今天是「构造上成立」的**。枚举与判定当前共用同一个谓词求值函数，所以两者一致不是被证明出来的，而是由结构保证的。**这一点值得直说，而不是让断言看起来证明了它没证明的东西**：它真正守的是将来有人给判定加快路径、两边开始漂移的那一天。为此另配了一条有齿性用例——注入一个两方向不一致的来源，比对必须报出分歧——确保这条断言不是空转。

**真风险（放行后续跟进）**：

1. **枚举与判定是否观察到同一份数据，内存实现测不出**。真实场景下枚举是离线批处理、判定是在线单点，两者看到的来源数据可能不同源、不同时。本轮内存实现下两者读同一份数据，**这不构成对真实实现的证明**。
2. **并发未被证明**。本轮无写入路径，但演练与真实模式并发对同一个键求值时，染色的竞态由 `experimentation` 的契约承担，本层未新增证据。

**本次不覆盖项**：

- `campaign` / `scenarios` 两层；业务场景 ①③④⑤ 的端到端表达。
- 真实数据源、真实存储、外部链路。
- 条件表达式的通用语言。本轮只做三类具体条件——来源侧属性、份号、依赖回流的时间窗。
- 预估规模、解释某人为什么在 / 不在、未解析条目统计。
- 人群定义的生命周期与停用（受众侧故事 19–22 均为 `待确认`）。
- 一份定义跨多个来源（受众侧故事 6 为 `待确认`）。
- **业务回归用例**：根 `AGENTS.md` 的「当前状态：尚未建立」在本轮**进一步部分解除**——业务场景 ② 的人群部分已落成会失败的测试（四个实验臂必须恰好划分基础人群，不重不漏）。其余场景与跨层部分仍未建立。

**需要后续动作的事项**：

- 人工裁定：本轮自行裁定的四项（人群定义不可变、模式不设零值、回流粒度必填、不做通用条件语言），是否认可。
- 「模式不设零值」若要成为通则，须按 `mechanization-claims` 规则 6 回头复核 `experimentation` 是否有同型缺口。本轮未做。
