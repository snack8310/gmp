## 背景与实现

用户在本地实验列表指出 CSS 与其他页面明显不同。对比活动列表、受众页和 `docs/product/design-system.md` 后，确认原实验页独有青绿色主按钮与链接、12px 圆角、阴影，以及卡片式列表。

- 实验列表改为复用活动页的 `section-heading`、`primary-link`、`campaign-table` 与可横向滚动表格容器；保留名称、ID、运行态、比例、染色策略、人群包数量及详情入口。
- 实验详情、新建页专属 CSS 改用现有变量、4px 卡片圆角和无阴影布局；运行态用中性标签，危险删除按钮用既有拦住色。
- 未修改实验分配、染色、缓存、路由、管理 API 或 Core。
