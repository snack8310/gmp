# 决策记录：动作（Action）为一等公民

关联：Snack 会话 2026-10-27（用户确认写入 gmp docs）；与同日分流组件运行时规则并行落盘

## 背景

活动文档早已写「动作与来源对称」（事实 36），但未明确**一等公民**地位，也未把「投放项 ≠ 动作类型 / 投放项引用动作 / 动作定义成功失败异步回执 / 展示位一次一结果」写成可引用边界。缺了这些，实现易把动作类型枚举写进投放项，或把展示回执语义与短信/发券混为一谈。

## 关键实现（仅文档）

- **动作是一等公民**（与来源、实验人群包同级）。
- **投放项 ≠ 动作类型**；**投放项引用动作**。
- **动作定义成功 / 失败 / 异步回执**；展示类不推翻事实 40（返回 id ≠ 被看见）。
- **展示位对应展示类动作**，通常一次一个展示结果。
- 活动侧事实 63–66；名词表与动作一节边界表；`system-boundaries` 归属表一行。
- 不变量：本轮**不新立**——静默失效面已由不变量 17、19 承接；承接表登记为不适用（概念边界）。
- **不改** `gmp-core`、不 push / commit。

## 风险与未覆盖项

1. 各动作契约的字段级成功/失败枚举未写——本轮只定「由动作定义」。
2. 素材仍非一等公民（事实 39）；与动作一等公民不冲突。
3. 展示「一次一个结果」与决策表多行路由的关系：一次判定仍只产出一个展示结果；多素材需求用多个投放项表达。
