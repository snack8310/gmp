# 实验库列表与详情的本地操作页

## 背景

原实验页只展示固定比例与说明，无法进入实验身份对应的详情调整比例或验证构造用户的模拟分组。用户确认先完成浏览器本地操作页，再决定管理 API 与 Core 的接入。

## 关键实现

- 实验库采用与活动页一致的列表、详情和新建样式；详情提供运行态、比例、只读分组预览与模拟首次分配。停用态禁止修改比例和模拟分配。
- 受众预览与实验详情共用本地实验定义和已记录的模拟染色；活动画布明确说明构造路径不代表当前实验分桶。
- 浏览器缓存读取时拒绝重复染色键与无效配置；旧版原文先备份再升级。写入失败时页面只提示当前会话状态。
- 活动受众区只保留受众管理入口。实验详情说明白名单、算法版本与盐、指标和放量配置尚未接入 Core。

## 关键文件

- `frontend/demos/operations-flow/audience.mjs`：实验定义、比例、模拟染色及缓存兼容边界。
- `frontend/demos/operations-flow/experiment-ui.mjs`：标准列表与详情、运行态操作及失败提示。
- `frontend/demos/operations-flow/activity-flow-canvas.mjs`：本地演练与实验分桶的区别说明。
- `frontend/demos/operations-flow/README.md`、`CHANGELOG.md`：使用范围与旧缓存回滚方法。

## 风险与未覆盖项

- 真风险（放行后续跟进）：跨标签页本地写入没有原子性；未来接入时须由服务端存储保证。旧版离线页无法直接读取新缓存，回滚须恢复备份键，升级后新增的本地修改不会在旧备份中。
- 本次不覆盖项：管理 API 与 Core 的实验定义、染色及指标接入；演示算法不作为生产分桶结论。
- 外部系统读写：实验配置与模拟染色只读写浏览器本地缓存；应用既有启动流程会向本机管理 API 同步受众引用目录，本次未新增该 API 写入；无 Core 或生产环境写入。
- 需要后续动作的事项：待用户验收本地页面后，另立任务设计 API 与 Core 接入。
