# 人群定义、复用实验与运营沙盘

关联 issue #50，分支 `feat/50-audience-management-demo`。本记录为 Draft 交付证据，尚未进入人工最终审核；原生浏览器验证缺失，独立评估当前为 `NEEDS-EVIDENCE`，不宣称完成。

## 背景与范围

用户要求将人群管理结合既有沙盘；随后明确人群编辑包含圈选条件和可选实验，实验与带实验的人群都可复用；画布继承不可取消，但可额外增加实验。实现仅位于 `frontend/demos/operations-flow/`，附任务卡；没有改变 `gmp-core`、领域规格、生产数据、CI 工作流或业务契约。

## 实现

- `audience.mjs` 提供构造样本、条件筛选、独立实验注册表、稳定展示分配和本地定义缓存。只保存规则及引用，不保存用户样本；旧版缓存兼容，损坏、孤立引用或写入失败时安全降级。
- `audience-ui.mjs` 提供人群编辑与共享实验选择器；名称、来源、国家、生命周期和天数按 AND 圈选。预览、列表与沙盘使用同一匹配函数。新建/改名实验独立明确保存，取消草稿不写回人群。
- `app.mjs` 移除策略闸机，人群池直接连接出口。继承实验只读，额外实验仅作用于选定 A/B 分支；没有继承时可作用于全体。额外配置不写回人群。
- `model.mjs` 用同一状态模型派生动画和人数，主、副对照不经过渠道。相同实验 ID 复用原分配，不重随机；不同实验 ID 使用独立展示盐。精确终点用绝对时点比较，避免浮点相减残留处理中人数。
- `export.mjs` 内联同版本样式与模块，生成离线自包含 HTML。没有网络运行依赖。

- 真风险（阻断正式验收）：原生浏览器排版、焦点与事件路由尚缺验证；仅作为 Draft 交付，不请求最终合并。
- 真风险（仅观察）：固定演示比例不表示生产算法；小样本比例可偏离。不同浏览器缓存不互通；会话降级刷新丢失会明确提示。

- 未讨论项：布局与重复交互仍交独立浏览器评估；已知访问阻断不得写成通过。
- 不覆盖生产规模、真实渠道、真实效果、跨浏览器全矩阵或通用流程引擎。

## 人群入口归属修订补充

用户进一步确认完整入口应在人群管理创建，画布只选择人群。`entry` 将批量排期与事件触发配置定义为互斥形状；来源仍仅保存在 `rules.source`，不制造双源。界面将来源移入进入方式区，共享后续圈选条件与实验。画布仅显示只读模式摘要和返回人群编辑入口。

事件预览明确为资格样本，而非实际事件数；沙盘播放不实现排期或订阅，多画布事件投递仍未决，不引入后端行为。v3 演示缓存兼容旧版缺省入口，明确提示解释为手动批量；当前版本损坏入口安全回退，不静默修复。没有业务数据迁移。
