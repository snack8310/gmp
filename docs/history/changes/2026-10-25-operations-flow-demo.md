# 运营流程立体展示 Demo

关联：issue #48。当前为待补浏览器证据的草稿交付，不代表人工最终确认。

## 背景与关键实现

用户需要直观看到人群进入、策略分流、渠道触达及成功 / 失败。用户认可展示后，明确要求展示层放在根目录 `frontend` 而非 `gmp-core`。

- 演示位于 `frontend/demos/operations-flow/`，由 HTML、CSS、JavaScript 模块组成，无前端框架或第三方运行依赖。
- 初版新增的 core 静态 Go 命令与 HTTP 测试已移除；最终 diff 中 `gmp-core` 与任务基线一致。根 README 与 `frontend/README.md` 说明层次边界。
- SVG 三维坐标投影显示立体台座、策略闸机、A/B 分组台、渠道终端和小人，提供场景、时间、视角与节点详情控件。
- 模拟结果由同一确定性状态函数派生位置和统计，区分未进入、处理中、成功、失败。成功仅为模拟回执，不代表转化。
- 时钟持有单一动画句柄。节点按下时记录标识，避免每帧替换 SVG 元素打断点选；仅拖动超过阈值才捕获指针。时间滑块使用任意精度步长，避免最末一人停在终点之前。
- `export.mjs` 将同版本源码内联为可直接打开的 HTML。迁移前后生成的 HTML 逐字相同，已认可的视觉与交互不变。

## 风险与未覆盖项

- 真风险（阻断正式验收）：原生鼠标点选、拖动、键盘时间定位、窄屏与系统减少动态偏好尚缺实际浏览器证据。处理器替身不模拟浏览器排版或事件路由，Draft PR 不请求正式合并。
- 真风险（仅观察）：SVG 投影不含真实光照、材质与物理碰撞；视角有限。
- 伪风险：真实触达不存在，页面不读取名单、不调用核心或渠道能力。
- 未讨论项：用户认可展示方向，但没有逐项确认原生交互与窄屏验收，不将其反馈记为全覆盖实测。
- JavaScript 测试目前手动执行，未改现有工作流，不声明已全部纳入 CI。
- 不覆盖真实渠道、真实转化率、生产性能、跨浏览器全矩阵或 WebGL。
