# 运营流程立体展示 Demo

关联：issue #48。当前为待补浏览器证据的草稿交付，不代表人工最终确认。

## 背景与关键实现

用户需要直观看到人群进入、策略分流、渠道触达及成功 / 失败，而不改动已有领域模型。

- 新增独立的 Go 静态展示入口 `gmp-core/cmd/gmp-flow-demo/`，默认仅监听本机，嵌入页面资源，无生产配置或渠道连接。
- 前端为零运行依赖的 SVG 三维坐标投影，显示立体台座、策略闸机、A/B 分组台、渠道终端和小人；提供场景、时间、视角与节点详情控件。
- 模拟结果由同一确定性状态函数派生位置和统计，区分未进入、处理中、成功、失败。成功仅为模拟回执，不代表转化。
- 时钟持有单一动画句柄。节点按下时记录标识，避免渲染替换 SVG 元素打断点选；仅拖动超过阈值才捕获指针。时间滑块使用任意精度步长，避免最末一人停在终点之前。
- `export.mjs` 将相同源码内联为可离线打开的单文件 HTML，作为预览不可达时的备用。不新增第三方运行依赖。
- 根 README 增加入口。既有核心领域、CLI、分层、工作流与权限不变。

## 风险与未覆盖项

- 真风险（阻断正式验收）：原生浏览器点选、拖动、键盘时间定位、窄屏布局与系统减少动态偏好尚缺实际浏览器证据。处理器测试不能替代浏览器事件与排版验证，Draft PR 不请求正式合并。
- 真风险（仅观察）：SVG 投影不提供真实光照、材质、物理碰撞；视角限制用于维持可读性。
- 伪风险：真实触达不存在，本入口不读取名单、不调用核心执行或渠道能力。
- 未讨论项处理：空间感已由离线场景图提供局部证据；真实 DOM、键盘、窄屏与低动态效果交人工后续验收，不把环境限制写成通过。
- JavaScript 测试目前手动执行，未新增 Node CI；现有 Go CI 会执行新命令的测试。不声明所有前端约束已由 CI 固化。
- 本次不覆盖真实渠道、真实业务转化率、生产性能、跨浏览器全矩阵或 WebGL。
