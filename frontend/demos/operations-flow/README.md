# 领域演示：受众、实验、运营与组合

独立前端展示 Demo：按受众、实验、运营三域查看对象，再在组合页引用并播放 SVG 沙盘。全部为构造数据，不接生产服务，不依赖 `gmp-core`、WebGL、框架、CDN 或第三方资产。

## 运行与导出

在仓库根目录启动：

```sh
python3 -m http.server 8080 --bind 127.0.0.1 --directory frontend/demos/operations-flow
```

打开 `http://127.0.0.1:8080`。多文件版使用 JavaScript 模块，需 HTTP 服务。

直接打开的单文件版：

```sh
node frontend/demos/operations-flow/export.mjs /tmp/gmp-audience-demo.html
```

生成器内联同版本样式与模块，不上传、不部署；HTML 可离线打开。运行时无外部依赖，Node 只用于测试与导出。

## 操作

### 受众

- 受众页管理可复用人群：名称搜索、新建、编辑、删除、取消、保存与实时预览。删除当前组合引用的人群时，组合会切到剩余的首个人群，或清空引用。进入方式包含批量来源及手动/每日 UTC 排期，或事件来源及预置模拟触发事件；国家、生命周期、未活跃天数按 AND 圈选。
- 可选引用**实验页已保存**的实验，本页只选 ID，不创建、改名或调整比例。匹配预览展示固定模拟池的资格人数和匿名样本；零匹配可保存，组合页不能播放触达。
- 点击「引用到组合」带入已保存人群。草稿不影响保存定义或组合；组合的「编辑此人群」返回本页。

### 实验

- 实验页集中创建、查看、改名与删除实验。被已保存人群引用的实验不能删除，须先解除引用。改名不改变 ID 或稳定分配。
- 比例固定为 A 45% / B 45% / 对照 10%。同一实验 ID 与模拟用户始终落在同一份；不同实验 ID 使用不同演示盐。小样本实际比例可能偏离目标值。染色和放量只有只读说明，不提供编辑器或指标界面。
- 人群与实验仍保存在本浏览器 `gmp-audience-demo-v1` 命名空间。可读旧版 v1/v2 缓存，明确保存时写 v3；损坏、禁用、版本不兼容或写入失败时提示并退回会话内存，刷新可能丢失修改。

### 运营

- `#campaign` 保留活动、投放项、活动流程边三张概念卡，点击「查看活动列表」进入 `#campaign/activities`；列表按活动名称、投放项数量展示，点击「查看详情」进入 `#campaign/activities/<活动ID>`。详情可返回列表，支持刷新深链及浏览器前进、后退；未知 ID 会显示未找到。
- 详情只读展示投放项清单及活动流程边关系表。每个投放项引用一个动作与一个人群；实验人群包臂显示包名和臂名。RCS 成功到邮件、失败到短信的结果含义来自演示动作说明，关系表不求值或播放。无投放项、无流程对象、无边及不可用引用均有单独提示；不可用引用保留原值。
- 活动种子及动作、人群引用目录在 `campaign-activities.mjs`，均为虚构构造数据，独立于受众和实验页的编辑数据。正常种子加载时校验 ID、引用和边端点；失效引用是单独构造的展示样例。运营不新增持久化，不修改 `gmp-audience-demo-v1` 的格式，也不接 `gmp-core`。本页不提供搜索、筛选、CRUD、装配和播放；跨层执行证据留在 `gmp-core/scenarios/`。

### 组合

- 组合页引用已保存人群并提供场景、SVG 沙盘、播放、暂停、重播、时间轴、倍速、节点详情和统计。切页或页面隐藏时暂停；切换人群、场景或流程实验节点会重置并暂停。
- 继承的人群实验只读。普通出口或继承 A/B 路径可添加一个进入后的流程实验节点，选择实验域已有项；主对照不触达、不能添加。节点只保存在当前会话，不写回人群。相同实验在继承和流程节点中复用时沿用原分配。
- 流程实验节点支持路径点选、检查器改引用及删除；沙盘不提供通用 Flow 图编辑。减少动态效果偏好下不绘制流动小人，主动播放仍更新统计。窄屏可通过按钮调整视角并横向选择节点。

## 口径与边界

- 模拟样本池固定为 240 个虚构记录，App 与白名单为互斥来源。国家、生命周期和未活跃天数都是本地生成的演示属性，不声称属于生产字段或口径。
- 匹配预览是此固定数据集的精确计算，不是生产预估；同一规则用于预览、列表计数与沙盘引用。
- 总人群 = 未进入 + 处理中 + 触达成功 + 触达失败 + 对照留存。处理中包含路上和等待回执，回执延迟不是失败。
- 节点累计到达不能跨节点相加为总人数；当前占用包含节点和其出站路段。主、副对照留存合计为不触达终态。
- 成功仅指模拟回执，不是阅读、下单或转化。渠道和结果为展示脚本，优化场景不是效果预测。
- 排期与触发类型仅演示配置；播放仍只模拟符合条件样本依次进入，不执行调度、事件订阅、重复事件处理或多画布分发。多画布事件归属与投递语义尚未确定，本 Demo 不替产品作决定。
- 不上传名单、不保存样本、不记录生产执行或染色、不接真实分桶、不发任何消息。没有账号、权限、后端、多用户同步或生产执行引擎。
- 这是展示沙盘，不是生产平台的流程引擎或领域语义实现。领域文档中尚待确认的功能不因本 Demo 变成业务决策。
