# 运营流程沙盘

用于讲解运营旅程的独立展示 Demo。位于 `frontend` 展示层，与 `gmp-core` 分离。使用自行构造的三维坐标与 SVG 投影绘制台座、闸机、渠道终端及小人，不依赖 WebGL、前端框架、CDN 或第三方资产。

## 运行

从仓库根目录使用任意静态 HTTP 服务，例如 Python 标准库：

```sh
python3 -m http.server 8080 --bind 127.0.0.1 --directory frontend/demos/operations-flow
```

打开 `http://127.0.0.1:8080`。无需 Go、npm 安装、配置文件、数据库、真实账号或密钥。JavaScript 模块需要 HTTP 服务，不建议直接双击多文件版的 `index.html`。

运行页面只需要 `index.html`、`style.css`、`app.mjs`、`model.mjs`，可由任意静态服务器托管。原来的 `gmp-core/cmd/gmp-demo` 仍是运行真实内存领域模型的命令行演示，两者互不依赖。

## 单文件备用

从仓库根目录执行：

```sh
node frontend/demos/operations-flow/export.mjs /tmp/gmp-flow-demo.html
```

生成的 HTML 内联相同版本的样式与模拟代码，可以直接打开，不依赖模块导入、HTTP 服务或外部资产。生成器只读前端源文件，并写入明确指定的输出文件；不上传、不部署。

## 演示操作

- 点击「开始模拟」或「暂停模拟」；「重置」回到零时刻并暂停。
- 场景可选均衡触达、回执延迟、优化示意。切换会清空当前进度并暂停，倍速保留。
- 拖动时间轴可观察任意时刻；速度可选慢速、正常、加速。
- 点击空间中的节点或左侧节点列表查看累计到达、当前占用、状态解释。
- 鼠标拖动场景调整视角；立体、俯视、缩放、复位提供按钮入口。手机保留按钮控制和横向节点列表。
- 所有列表与播放控件支持键盘。系统启用减少动态效果时默认暂停，播放只更新数值，不绘制流动小人。页面隐藏时自动暂停，不自动恢复。

## 口径与边界

- 固定演示样本为 240 位虚拟用户，全部在浏览器内存中计算；A/B 组与渠道均按脚本固定分配，不调用生产分桶算法或真实领域模型。
- 总人群 = 未进入 + 处理中 + 触达成功 + 触达失败。处理中包括路上与等待回执；失败是终态，不把延迟算作失败。
- 节点「累计到达」是经过该节点的人数，同一个人在多个节点均可出现；不能把不同节点累计数相加当成总人群。
- 节点「当前占用」包括该节点及其出站路段上的虚拟用户，终态节点不再占用处理名额。
- 「成功」只指模拟触达成功回执，不表示阅读、下单或业务转化。优化场景只是预设数据变化，不是真实效果预测。
- 无真实名单、号码、渠道发送、网络 API 调用、生产连接、存储或自动重试。
- 场景为 SVG 三维投影，不是真实光照、材质、物理仿真或 WebGL 渲染。视角有意限定以保证可读性。

## 验证

从仓库根目录执行：

```sh
node --test frontend/demos/operations-flow/*.test.mjs
node --check frontend/demos/operations-flow/app.mjs
node --check frontend/demos/operations-flow/model.mjs
node --check frontend/demos/operations-flow/export.mjs
```

Node 仅用于测试和导出，运行页面无需 Node。模型测试覆盖确定性、全程计数守恒、终态、延迟场景，以及时钟的重复启动、暂停、重置、倍速和结束清理。无浏览器处理器测试覆盖重绘期间点选、拖动与触摸区别、减少动态效果分支；不替代真实浏览器验收。JavaScript 测试目前需手动执行，未改动现有工作流。

真实渠道联调、生产性能、跨浏览器全矩阵不在验证范围内。回滚只需移除本 Demo 目录及文档入口，不涉及 `gmp-core` 或业务数据。
