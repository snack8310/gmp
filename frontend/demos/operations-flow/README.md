# 人群与运营实验室

独立前端展示 Demo：先管理可复用的人群定义，再引用到 SVG 立体运营沙盘。全部为构造数据，不接生产服务，不依赖 `gmp-core`、WebGL、框架、CDN 或第三方资产。

## 运行与导出

在仓库根目录启动：

```sh
python3 -m http.server 8080 --bind 127.0.0.1 --directory frontend/demos/operations-flow
```

打开 `http://127.0.0.1:8080`。多文件版使用 JavaScript 模块，需 HTTP 服务。

直接打开的单文件版：

```sh
node frontend/demos/operations-flow/export.mjs /tmp/gmp-audience-demo.html
```

生成器内联同版本样式与模块，不上传、不部署；HTML 可离线打开。运行时无外部依赖，Node 只用于测试与导出。

## 操作

- 人群管理提供预置定义、名称搜索、新建、编辑、取消与保存。编辑器保存完整可复用入口：进入方式、通用圈选条件与可勾选的 A/B 实验。
- 进入方式在人群管理选择批量或事件。批量保存来源与手动/每日 UTC 排期；事件保存来源与预置模拟触发事件（App 打开、订单支付、领取权益）。画布入口不提供模式、排期或事件编辑，只选择已保存人群并只读显示配置。
- 来源只保存一份（`rules.source`），进入方式保存于 `entry`：批量仅含排期，事件仅含触发类型，切换模式后不保留另一分支。再叠加国家、用户生命周期、未活跃天数范围；所有条件按 AND 同时满足，天数包含边界。
- 右侧实时显示匹配数、比例及匿名模拟样本。事件模式下这是可判定资格的样本数，不是已到达事件数或实际进入人数。名称未填仍可看规则预览，但不能保存；非法天数不可计算。零匹配可保存，引用后不能播放触达。
- 保存的是入口配置、规则与可选 `experimentId` 引用，不是名单。实验注册表独立保存 ID 和名称，同一实验可以被多个人群引用；带实验的人群可以被多个模拟场景引用。两者仅存在本浏览器 `gmp-audience-demo-v1` 命名空间中。存储禁用、损坏、版本不兼容或写入失败时会显示提示并降级为当前会话内存；刷新可能丢失修改。不跨设备同步。
- 点击「引用到沙盘」，或在沙盘选择已保存人群。草稿不会污染保存的定义；切换人群、修改当前引用定义、场景或额外实验配置会重置并暂停。切换或更新人群还会清空画布额外实验，避免隐式套用。
- 人群默认不引用实验，符合条件用户从单一出口进入画布。勾选实验后可复用已有实验，或新建/改名独立实验。Demo 比例固定为 A 45% / B 45% / 对照 10%，名称可编辑，ID 和比例不随改名变化；不建设生产实验配置平台。
- 画布继承的人群实验只读，不提供取消或替换；「编辑此人群」返回源定义。人群池直接连接 A/B/对照出口，没有策略闸机。
- 画布可以额外引用一个实验。已有继承实验时只能作用于 A 或 B 分支，无继承实验时可作用于全体；显示额外实验名称、分支分母及分配人数。主实验身份不因副实验改变。
- 相同实验 ID + 相同模拟用户始终分到相同组，不因改名、条件、引用处或播放改变。额外复用与继承相同的实验时沿用原结果，不再随机切分；因此该分支可能全部进入同一出口，这是预期行为。不同实验 ID 使用不同展示盐。
- 实际小样本比例可偏离目标区间。主、副对照都明确存在、不进入渠道、不计入成功或失败。属性条件决定「是否符合」，实验决定「符合后落在哪组」。画布额外实验仅保留当前会话，不写回人群。
- 新建或改名实验有独立的「保存实验」动作。取消人群草稿不会删除已经明确保存的独立实验；未保存的实验名称编辑可单独取消。缓存写入 v3，可读取 v1/v2：缺少入口配置的旧定义解释为手动批量并显式提示，读取不改写缓存，下一次明确保存写入新版；v3 入口缺失或非法不会默认修复。异常或孤立实验引用安全降级，不覆盖损坏原文。
- 原沙盘支持开始、暂停、重播、时间轴、倍速、场景切换、节点详情、拖动旋转、俯视和缩放。切到人群管理或页面隐藏时暂停。
- 系统启用减少动态效果时不绘制流动小人；主动播放仍更新统计。手机可用按钮调整视角、横向选择节点。

## 口径与边界

- 模拟样本池固定为 240 个虚构记录，App 与白名单为互斥来源。国家、生命周期和未活跃天数都是本地生成的演示属性，不声称属于生产字段或口径。
- 匹配预览是此固定数据集的精确计算，不是生产预估；同一规则用于预览、列表计数与沙盘引用。
- 总人群 = 未进入 + 处理中 + 触达成功 + 触达失败 + 对照留存。处理中包含路上和等待回执，回执延迟不是失败。
- 节点累计到达不能跨节点相加为总人数；当前占用包含节点和其出站路段。主、副对照留存合计为不触达终态。
- 成功仅指模拟回执，不是阅读、下单或转化。渠道和结果为展示脚本，优化场景不是效果预测。
- 排期与触发类型仅演示配置；播放仍只模拟符合条件样本依次进入，不执行调度、事件订阅、重复事件处理或多画布分发。多画布事件归属与投递语义尚未确定，本 Demo 不替产品作决定。
- 不上传名单、不保存样本、不记录生产执行或染色、不接真实分桶、不发任何消息。没有账号、权限、后端、多用户同步或生产执行引擎。
- 这是展示沙盘，不是生产平台的流程引擎或领域语义实现。领域文档中尚待确认的功能不因本 Demo 变成业务决策。
