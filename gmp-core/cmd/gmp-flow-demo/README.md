# 运营流程沙盘

用于讲解运营旅程的独立展示 Demo。Go 只提供静态资源，前端使用自行构造的三维坐标与 SVG 投影绘制台座、闸机、渠道终端及小人，不依赖 WebGL、框架、CDN 或第三方资产。

## 运行

在 `gmp-core` 目录执行：

```sh
go run ./cmd/gmp-flow-demo
```

打开 `http://127.0.0.1:8080`。默认仅监听本机；需要修改端口时使用 `-addr 127.0.0.1:8081`。无需配置文件、数据库、真实账号或密钥。已有 `cmd/gmp-demo` 仍用于运行真实的内存领域模型，本演示不替代它。

也可以将 `web/index.html`、`web/style.css`、`web/app.mjs`、`web/model.mjs` 放在同一个静态 HTTP 目录下。JavaScript 模块需要 HTTP 服务，不建议双击 HTML 文件。

## 演示操作

- 点击「开始模拟」或「暂停模拟」；「重置」回到零时刻并暂停。
- 场景可选均衡触达、回执延迟、优化示意。切换会清空当前进度并暂停，倍速保留。
- 拖动时间轴可观察任意时刻；速度可选慢速、正常、加速。
- 点击空间中的节点或左侧节点列表查看累计到达、当前占用、状态解释。
- 鼠标拖动场景调整视角；立体、俯视、缩放、复位提供按钮入口。手机保留按钮控制和横向节点列表。
- 所有列表与播放控件支持键盘。系统启用减少动态效果时默认暂停，播放只更新数值，不绘制流动小人。页面隐藏时自动暂停，不自动恢复。

## 口径与边界

- 固定演示样本为 240 位虚拟用户，全部在浏览器内存中计算；A/B 组与渠道均按脚本固定分配，不调用生产分桶算法或真实领域模型。
- 总人群 = 未进入 + 处理中 + 触达成功 + 触达失败。处理中包括路上与等待回执；失败是终态，不把延迟算作失败。
- 节点「累计到达」是经过该节点的人数，同一个人在多个节点均可出现；不能把不同节点累计数相加当成总人群。
- 节点「当前占用」包括该节点及其出站路段上的虚拟用户，终态节点不再占用处理名额。
- 「成功」只指模拟触达成功回执，不表示阅读、下单或业务转化。优化场景只是预设数据变化，不是真实效果预测。
- 无真实名单、号码、渠道发送、网络 API 调用、生产连接、存储或自动重试。
- 场景为 SVG 三维投影，不是真实光照、材质、物理仿真或 WebGL 渲染。视角有意限定以保证可读性。

## 验证

在 `gmp-core` 目录执行：

```sh
go build ./...
go vet ./...
go test ./...
node --test cmd/gmp-flow-demo/web/*.test.mjs
node --check cmd/gmp-flow-demo/web/app.mjs
node --check cmd/gmp-flow-demo/web/model.mjs
```

Node 仅用于运行前端测试，演示运行无需 Node。模拟测试覆盖确定性、全程计数守恒、终态、延迟场景，以及时钟的重复启动、暂停、重置、倍速和结束清理。无浏览器处理器测试覆盖重绘期间点选、拖动与触摸区别、减少动态效果分支；不替代真实浏览器验收。Go 测试覆盖静态资源与只读 HTTP 边界。Go 测试由现有 CI 执行，JavaScript 测试目前需手动执行，未改动现有工作流。

真实渠道联调、生产性能、跨浏览器全矩阵不在此演示的验证范围内。回滚只需移除本命令目录及根 README 的入口，不涉及业务数据回滚。

## 单文件备用

需要离线直接打开时，在 `gmp-core` 执行：

```sh
node cmd/gmp-flow-demo/export.mjs /tmp/gmp-flow-demo.html
```

生成的 HTML 内联相同版本的样式与模拟代码，不依赖模块导入、HTTP 服务或外部资产。生成器只读前端源文件，并写入明确指定的输出文件；不上传、不部署。
